**Voters Dashboard**

A Python-based interactive data visualization dashboard designed to analyze and explore voter demographics, including age distribution, gender breakdowns, and filtered dataset metrics.

📊 Features
Demographic Analysis: Visualizes voter metrics categorized by gender and age groups.

Data Filtering: Leverages custom-filtered datasets to deliver precise insights and clear trend charts.

Interactive UI: Built for seamless data exploration and reporting.
